    There are many ways to contribute to TAPPaaS:

    Contribution Type Description Get Started
    Code Fix bugs, add features, improve performance Contributing Guide
    Documentation Improve guides, fix typos, add examples Contributing Guide
    Issues Report bugs, suggest features GitHub Issues
    Support Help others in discussions GitHub Discussions
    Spread the Word Blog posts, talks, social media Share your experience!

    • Community spotlights and shoutouts
