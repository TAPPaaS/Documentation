# The Foundation

What the TAPPaaS foundation consists of, and how each part is designed:

- **[Network](network.md)** — network topology and zone/VLAN design
- **[Storage](storage.md)** — data storage design
- **[Security](security.md)** — security architecture and controls
- **[Single Sign-On](single-signon.md)** — identity and authentication
- **[Backup](backup.md)** — backup and recovery design

How the software behind each part gets chosen is a principle, not an accident — see
[Software Selection](software-selection.md) under Principles.

## The module model

Everything above is delivered as **modules** — the smallest deployable units, each
declaring what it provides and what it depends on in its own json. The dependency
graph is therefore *computed from the modules themselves* (regenerated by
`src/generate-module-dependencies.sh` in the source repo):

[:octicons-arrow-right-24: Module Dependencies](../../generated/module-dependencies.md)

The catalog of foundation modules lives under
[Stacks → Foundation](../module-designs/foundation.md).
